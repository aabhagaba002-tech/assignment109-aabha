Q1Remembering

List four characteristics of a modern digital computer and identify the key hardware technology of the five generations.

Characteristics

  1. Speed – executes billions of instructions per second (GHz clock, MIPS/FLOPS).
  2. Accuracy – errors come only from wrong input or program (GIGO), not from the machine.
  3. Storage – holds huge data and programs in memory and secondary storage, recalled instantly.
  4. Automation / Diligence – once a program is loaded it runs without human help and never tires.

(Others: versatility, connectivity, no IQ.)

Q2Understanding

Explain the flow of data, instructions and control signals in the functional block diagram.

  • Data flow: Input devices convert user data to binary and send it to memory. The ALU fetches operands from memory, processes them, and stores results back; results then go to output devices.
  • Instruction flow: The program is loaded into memory. The control unit fetches each instruction (using Program Counter & Instruction Register), decodes it, and executes it – the fetch–decode–execute cycle.
  • Control signals: The control unit issues timing and control signals (read/write, enable, clock) to ALU, memory and I/O interface so every part works in the right order. It does not process data itself – it only directs.
  • Interaction: CPU ↔ memory over address, data and control buses; the I/O interface matches the speed and format of slow peripherals to the fast CPU (buffers, ports, interrupts).
Q3Applying

Demonstrate deployment of optical scanners and card readers on a campus.

A) Student attendance

  1. Each student gets an ID card with a RFID chip (and a barcode as a backup).
  2. An RFID reader is fixed at each classroom door. The student taps the card; the reader captures the unique ID.
  3. The reader sends the ID, time and room to the campus server, which matches it with the timetable and marks the student Present / Late.
  4. OMR scanner reads fill-in-the-bubble sheets for MCQ tests and manual attendance sheets, and stores scores in the database automatically.
  5. Reports go to teachers and parents; absentee alerts can be sent by SMS.

B) Library checkout

  1. Every book has a barcode (or RFID tag); every member has a smart card.
  2. At the counter / self-service kiosk, the student taps the smart card, then a barcode scanner reads each book.
  3. The library software verifies membership and fines, records issue date and due date, and updates stock.
  4. On return, scanning the book clears the record. An RFID gate at the exit alarms if an un-issued book passes.

Benefits: faster than manual registers, no proxy attendance, fewer errors, instant reports, theft control, less staff workload.

Q6Evaluating

Assess: plotter vs UHD monitor + large-format printer for civil engineering blueprints.

CriterionDrum/Flatbed plotterUHD monitor + wide-format printer
Line resolutionPen draws true continuous vector lines; razor-sharp, accurate to ~0.01 mmRaster dots (600–1200 dpi); very good, but thin lines can look stepped. A monitor shows only a screen preview
ScalabilityVector drawings scale to A0 or longer rolls without quality loss; slow on complex drawingsFast, handles colour, images, GIS and shading; size limited by printer width
CostPen plotters are cheap to run but slow and mechanical (wear); modern inkjet plotters are efficientHigher setup cost; ink/toner is costly, but one machine also prints posters, reports and renders

Decision: For pure line blueprints, a plotter is superior – best accuracy, dimensional fidelity, and durable output. In practice, a modern firm should use a large-format inkjet plotter (the plotter and printer merged) together with a UHD monitor only for design and review. Pen/drum plotters are justified only for archival-grade line work; a UHD monitor is never the final output.

Critique facial recognition vs voice recognition as primary biometrics in noisy, public places.

Facial recognition (vision input)Voice recognition
ReliabilityUnaffected by noise. Hurt by glare, rain, low light, angle, masks, crowds. Fixable with IR camerasVery poor: background noise ruins speech capture; wind, crowd and distance raise false rejections

Verdict: in loud public areas, face recognition (with IR + liveness check) is more reliable; voice is unsuitable as the primary factor. For high security, use multi-factor authentication (face + card/PIN), and use voice only in quiet, private spots.

Q8Creating

Design a hands-free workstation for a visually impaired user.

Components

  • Input: noise-cancelling headset microphone with voice recognition (dictation + commands: "open mail", "read next"); tactile keyboard with raised home-row markers or Braille keyboard; optional trackball with tactile buttons; OCR scanner that turns printed pages into speech.
  • Output: screen reader (NVDA / JAWS / VoiceOver) with text-to-speech voice response synthesizer reading menus, text and alerts; refreshable Braille display for silent reading and precise editing; audio cues and earcons for errors and confirmations.
  • Integration: voice recognition and the keyboard feed the operating system. The screen reader reads every focus change aloud, while the Braille display mirrors it. A smart assistant handles hands-free tasks (email, calendar, web).
  • Workspace design: fixed, uncluttered layout with tactile markers; cables managed; headset use for privacy; good microphone placement to avoid noise; high-contrast, large-print screen for partially sighted helpers.
  • Support features: keyboard shortcuts, adjustable speech speed, auto-backup, privacy mode for sensitive data.

Result: the user hears feedback for every action and can work independently, accurately and with privacy.
